# 外部再电离历史：验证与已知边界

日期：2026-10-16。上游基准：CAMB 2.0.5，
`1d1d3d6d09e499291651855d4d8286419030a32b`。
本 fork 版本：`2.0.5+tabulated.2`（2026-10-18 更新，见文末“tabulated.2 更新”）。
接口与公式见[使用说明](tabulated_reionization.md)。

## 修改范围

新增 Python/Fortran `TabulatedReionization`、C2 局部保界插值、函数自适应采样和表格取回接口。
通用 CAMB 计算只增加三处必要支持：

1. 再电离模型可请求局部源时间采样；原有模型默认返回空请求，不改其原有时间网格。
2. 额外电子不透明度穿过零时，额外光深积分改用有符号梯形公式，避免异号调和平均的奇异性。
   同号非零时保留原有公式。
3. （tabulated.2）新增只读接口 `CAMBdata.get_reionization_optical_depth()`，
   返回热力学积分已经算出的再电离光深；不改变任何计算结果。

没有修改原生 tanh/exp 的参数定义或人为修补其尾部，也没有切换原科学项目的生产 CAMB。
构建、测试均与原 `1.6.6` patched 后端隔离。原 CAMB 许可证和归属声明保留。

### 插值与 API 检查

- 15 项纯插值测试，包括 80 组随机、不规则、非单调的 `[0,1]` 数据；
  检查所有 Bernstein 控制点、密集求值点的局部凸包，以及节点两侧一、二阶导数连续。
- 零电离贡献恢复复合残余；充分电离和独立 HeIII 项符合当前 `YHe` 的电子预算。
- 显式高红移连接不改表内节点；低红移部分电离不被强制改成充分电离。
- 允许总丰度穿过复合基线，额外光深不发生异号调和平均奇异性。
- 检查非法输入、氦预算、错误采样控制、复制隔离、公开数组取回、禁止歧义反演和不完整序列化。

插值限制器也对**节点值的变化保持连续**。原先的统一缩放方案曾有以下失败例：
`z=[0,1,2], y=[0,1,0]`，末节点增加 `1e-12`，区间中点可突然改变约 `0.09375`。
现在先连续裁剪共享一阶导数，再裁剪共享二阶导数到相邻 Bernstein 约束的交集；
该例整条曲线的最大变化约 `1e-12`，不再出现有限跳变。

这**不承诺参数处处可微**。固定网格、limiter 未激活的 tanh 参数有限差分测试呈预期的
二阶步长收敛；limiter 切换、自适应节点变化和源分区变化仍要求实际 Fisher/梯度应用检查步长。
只在机器精度上可分的用户节点明确拒绝；自动生成网格和 breakpoints 的 roundoff 碰撞会合并。

## 同一条历史：原生 tanh 与自由接口

宇宙学：`H0=67.4, ombh2=0.0224, omch2=0.12, mnu=0.06, YHe=0.245`，
`As=2.1e-9, ns=0.965`。原生 `zrei=8`。
`lmax=300, DoLensing=False, lens_potential_accuracy=0`；
`AccuracyBoost=2, BackgroundTimeStepBoost=2, TimeStepBoost=2`。

从原生实际背景取得包含 residual 和 HeIII 的总 `x_e(z)`，以 `total_xe` 输入自由接口；
**不再添加一次 HeIII**。覆盖 `[0,80]`，显式连接宽度 1；
函数采样 `max_dz=1, rtol=0`，绝对探针容差依次为 `1e-4,1e-5,1e-6`。
实际背景在 4001 点上比较；谱比较范围 `ell=2..100`。

TT/EE 采用最大相对差；TE 使用 `abs(delta TE)/sqrt(TT*EE)`，不在 TE 过零处取相对误差。
光深用 8001 个红移点独立密度积分，并与 opacity 积分交叉验证至 `rtol=2e-6`：

`tau[0,80] = c*sigma_T*n_H0 * integral_0^80 ((1+z)^2*x_e/H(z)) dz`。

这里 `n_H0=(1-YHe)*rho_b0/m_H`，`H(z)` 用 SI 单位。
这包含该区间的复合残余，**不是** CAMB 参数 `tau` 所定义的纯再电离贡献。
测试要求精细档 `max|delta x_e|<1e-5`、`|delta tau[0,80]|<1e-6`，
以及 TT/EE/归一化 TE 差均小于 `1e-3`；不是只验证光深。

本机精细档 270 个节点：`max|delta x_e|=8.40e-7`，
`|delta tau[0,80]|=1.63e-10`；最大 TT、EE 相对差分别为 `3.68e-5`、`3.47e-6`，
最大归一化 TE 差 `4.80e-5`。TT 仍有有限背景/时间网格差，不能把函数探针容差直接当成谱误差。
完整的三档结果由测试打印。

原生指数模型的背景精细档使用 297 个节点，`max|delta x_e|=7.97e-7`，
`|delta tau[0,80]|=1.46e-8`；不附加未经原生参考收敛验证的 TT 精度宣称。

## 高红移非单调历史自身的数值收敛

测试节点：

```text
z: 0  5   8   12  40  50    55    60    70  80
q: 1  1   .5   0   0   .05   .15   .05   0   0
```

关闭额外 HeIII，采用 `ionized_fraction`。这是一条刻意含显著早期电离的压力测试，
**不是声称它符合当前观测约束**。保持输入历史不变，单独增加背景和源采样，
不把“变了插值函数”混成“同一函数的积分精度”。
其余宇宙学同上，`AccuracyBoost=2, TimeStepBoost=2`。

| 加密项 | 最大相对 TT 差 | 最大相对 EE 差 | 最大归一化 TE 差 |
| --- | ---: | ---: | ---: |
| BackgroundTimeStepBoost 2 → 4，源区间采样 16 | 1.2621e-4 | 7.4807e-7 | 8.3416e-5 |
| 源区间采样 16 → 32，BackgroundTimeStepBoost=4 | 8.1698e-5 | 2.1774e-5 | 5.3889e-5 |

`tau[0,80]` 分别为 `0.0941339104946, 0.0941339106183, 0.0941339106183`。
因此选定的这条 `z≈55` 非单调历史通过本次低多极 `1e-3` 加密门槛。
默认源区间采样提高到 16；密表成本随节点数增加，不建议把极密输入当成无成本精度提升。

## 原生指数模型：为何不冒充收敛的 TT 金标准

原生 `ExpReionization(zrei=8)` 的高红移开始点约为 `31.346653521`。
上游 `get_timesteps` 以指数尾部 `1e-4` 定义此处；热力学循环在此以上使用复合解，
以下调用仍含非零指数尾部的模型，因此存在一个有限的小跳变。
不是我们的表格插值人为产生这个截断。

独立安装、完全未修改的官方 PyPI CAMB 2.0.5 复现了同样的精度敏感性。
例如 `lmax=100` 的一次指数模型检查中，仅改变 `AccuracyBoost=1,2,4`，
官方 TT 的 `ell=2`（原始 `C_ell`，`muK^2`）分别为
`1066.26000364, 1089.61649821, 1071.99992526`；本分支原生模型给出相同结果至约 `2e-7`。
这组设置不能作为精确 TT 参考。

进一步的官方背景检查中，`AccuracyBoost=2, BackgroundTimeStepBoost=4`：
handoff 附近 `max|ddvisibility|≈3.96e-7 Mpc^-3`，而真实再电离完成区约为 `4.57e-10 Mpc^-3`，
并能观察到 `x_e` 的背景样条振铃。TT 源含 `dvisibility` 和 `ddvisibility`，
EE 不包含这类同阶导数项；这与 TT 明显更敏感相符。
**这是有源码和独立数值支持的根因候选，不等于已证明全部谱差都来自这一处。**

因此指数模型自动测试验证原生实际 `x_e` 和独立总光深；不把未经收敛证明的原生 TT
设为通用金标准，也没有通过偷偷改变指数尾部来获得“相同模型”的假一致。
原生 tanh 的谱对照和自由历史自身的背景/源加密是两个独立验收门槛。

## 结果的适用范围

- 这里验证了上述平直宇宙学、无透镜标量谱的低多极范围。没有针对任意宇宙学、
  极窄峰、复合时期、高多极、透镜、张量、物质谱或实际似然给出统一精度证明。
- 表格与显式连接为 C2，不表示所有继承的上游氦尾部/复合过程都被重写为全局 C2。
- `set_function` 的容差是函数值探针误差，不是导数、积分或谱的严格全域误差上界。
  未声明的任意窄峰可能被有限采样漏过；必须提供物理特征尺度、breakpoints 并检查加密。
- 不求解自洽电离、能量注入、热演化或 patchy 再电离。来自非均匀模拟的体积平均
  中性比例也不能未经平均方式审查直接等同于平均电子密度。
- 原生指数模型的既有问题不在本次补丁中顺手更改；正式使用它作谱参考时须单独处理。
  对新的外部历史，仍须重复本报告的输入、背景和源采样三层验证。

科学定义及其文献依据见[使用说明的参考资料](tabulated_reionization.md#参考资料)，
特别是 CAMB v2 的电子/加热约定、FlexKnot 的历史先验和高红移再电离文献。

## tabulated.2 更新（2026-10-18）

### 1. 额外源采样按区间宽度分配（提速，不降精度）

旧规则给每个有变化的区间固定 `source_samples_per_interval=16` 个额外源采样，
总采样数正比于节点数：节点越密，CAMB 越慢，而谱精度在默认全局精度下并不提高。
新规则见[使用说明](tabulated_reionization.md)第 4 条：每区间
`min(16, max(2, ceil(Δln(1+z)/0.005)))`。宽区间（稀疏表）不受影响；窄区间（密表）只取 2–4 个。

用原生 tanh（`tau=0.0576`）的实际 `x_e(z)` 作 `total_xe` 表，在相同历史下与原生模型比较
（`lmax=2500`，透镜总谱，`lens_potential_accuracy=1`，默认全局精度，8 线程，三次取最快，先丢弃首次调用）：

| 节点数 | 旧：每区间 16 | 新：按宽度分配 | 与原生谱最大差（新） |
| ---: | ---: | ---: | --- |
| 178 | 2.30 s（2.4× 原生） | 0.97 s（1.0×） | TT 1.6e-4，EE 9.3e-5，TE 1.0e-4 |
| 412 | 4.22 s（4.4×） | 1.12 s（1.2×） | TT 2.5e-4，EE 1.5e-4，TE 1.6e-4 |
| 754 | 8.23 s（8.5×） | 2.02 s（2.1×） | TT 2.6e-4，EE 1.6e-4，TE 1.7e-4 |

原生 tanh 自身相对 `TimeStepBoost=4` 的差为 TT 3.1e-4、EE 8.9e-4，
因此表中差异处在 CAMB 默认精度以内。178/412 节点新旧规则相对原生的差异几乎相同；
754 节点旧规则因多采样比原生“更精”（EE 6.1e-4 的差来自其更细采样），新规则回到原生精度水平。

稀疏表不受影响：十节点 `z≈55` 峰压力测试中各区间宽于 `Δln(1+z)=0.08`，新旧采样完全相同。
该表确实需要每区间 16 个采样：相对极细采样，每区间 4/8/16 个时 TT 最大差为 2.0e-2/7.7e-3/3.5e-4。
这说明默认上限 16 不能下调，节点稀疏时应保留。

### 2. 节点密度与插值误差（与源采样分离）

在 `min_steps=4000` 的固定稠密源采样下只改变节点密度，参考为 `ln(1+z)` 间隔 0.002（1720 节点）。
tanh 型（`q=[1-tanh((z-8)/0.7)]/2`）与非对称型（z=6 结束、高红移长尾）结果：

| `ln(1+z)` 间隔 | 节点数 | tanh：EE / `|Δτ|` | 非对称：EE / `|Δτ|` |
| ---: | ---: | --- | --- |
| 0.01 | 347 | 2.8e-7 / 5e-11 | 5.8e-7 / 8e-9 |
| 0.02 | 175 | 2.5e-6 / 3e-8 | 3.3e-6 / 2e-8 |
| 0.03 | 118 | 4.7e-5 / 6e-7 | 1.8e-5 / 4e-7 |
| 0.05 | 72 | 5.3e-4 / 7e-6 | 1.3e-4 / 2e-6 |
| 0.10 | 38 | 3.2e-3 / 4e-5 | 1.7e-3 / 3e-5 |
| 0.20 | 20 | 3.9e-2 / 6e-4 | 1.8e-2 / 3e-4 |

TT 差均小于 EE 差（最大 1.8e-3，出现在 0.20 间隔）。插值误差主要来自电离分数变化最快的区间。

### 3. 光深接口

`get_reionization_optical_depth()` 与独立密度积分（总 `x_e` 减去关闭再电离与氦步骤的复合解）
对 tanh 与非对称历史分别相差 1.5e-5 与 6.5e-6（相对）；原生 tanh `set_tau(0.055)` 返回 0.055（容差 1e-4）。
同一 tanh 表中，He II → He III 步骤贡献 0.00133。
